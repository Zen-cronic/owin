Why it exists

I built Owin because a buyer’s security questionnaire asks whether your AI providers keep customer data, and the true answer differs per endpoint.

Anthropic’s Messages API can run under zero data retention, its MCP connector is not covered, and Message Batches keep data for 29 days. For each endpoint you run, Owin fills the AI section from the vendor’s own page: retention, training, ZDR, region, who sees it. An answer goes Stale when that page changes after you wrote it, and when Owin’s three readings disagree, it asks you.
